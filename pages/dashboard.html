The KingVamp promise

Other script managers have been caught collecting browsing data. KingVamp is built the opposite way: everything - your scripts, settings, values and logs - lives only in this browser on this device. There is no KingVamp server that receives anything. You can verify this yourself in the Privacy Guard tab: KingVamp never appears there, because it never phones home.
